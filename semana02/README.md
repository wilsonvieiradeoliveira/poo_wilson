# Semana 02 — Funções, Listas e Dicionários

Exercícios sobre funções, estruturas de dados (`list` e `dict`) e a combinação das duas. Ordem sugerida de estudo:

| # | Arquivo | Tópico |
|---|---------|--------|
| 01 | `01_saudacao.py` | função simples, sem retorno |
| 02 | `02_dobro.py` | função com `return` |
| 03 | `03_desconto.py` | função com cálculo e retorno |
| 04 | `04_playlist.py` | lista: indexação e `len()` |
| 05 | `05_playlist_append.py` | lista: `append()`, `remove()`, `in`, `for` |
| 06 | `06_playlist_esqueleto.py` | função + lista dentro de um menu interativo |
| 07 | `07_dicionario_ficha_de_cadastro.py` | dicionário: criação e leitura |
| 08 | `08_dicionario_lendo_adicionando.py` | dicionário: leitura, alteração, criação de chave, `.items()` |
| 09 | `09_dicionario_lista_de_dicionarios.py` | lista de dicionários (combina os dois conceitos) |

> Nota: `09_dicionario_lista_de_dicionarios.py` foi renomeado de `dicionario_adicionando_dados.py` — o nome antigo sugeria adição de dados, mas o conteúdo apenas percorre uma lista de dicionários já pronta.
