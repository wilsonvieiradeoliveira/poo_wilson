# Semana 03 — Classes, Objetos, Atributos e Métodos

Introdução à Programação Orientada a Objetos: criação de classes, instanciação de objetos, atributos, métodos e o `self`. Ordem sugerida de estudo:

| # | Arquivo | Tópico |
|---|---------|--------|
| 01 | `01_perfil.py` | classe + método simples (mini-desafio aula 3: `Perfil.seguir()`) |
| 02 | `02_personagem.py` | dois objetos interagindo (`atacar(alvo)`), `esta_vivo()`, `status()`, batalha em `while` |
| 03 | `03_playlist2.py` | classe `Musica` + menu interativo (playlist 2.0, sem dicionários) |
| 04 | `04_s3_ex1.py` | classe vazia (`pass`), atributos definidos com `.` |
| 05 | `05_s3_ex2.py` | classe `Aluno` + `if` sobre atributo (aprovado / em recuperação) |
| 06 | `06_s3_ex3.py` | lista de objetos (catálogo de produtos) + `for` |
| 07 | `07_s3_ex4.py` | métodos (`exibir`, `aplicar_desconto`) e `self` |
| 08 | `08_s3_ex5.py` | métodos que alteram o próprio objeto (`ganhar_pontos`) |
| 09 | `09_s3_desafio_personagem.py` | mini-desafio aula 4: 3 combinações de ataque/vida, comparando quem vence |

> Exercício 1 e mini-desafio da Aula 1 (caça-objetos e mapeamento de atributos/métodos) foram feitos no caderno, conforme pedido na apostila.
