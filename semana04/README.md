# Semana 04 — O construtor `__init__` e os tipos de atributo

O construtor `__init__`, valores padrão de parâmetro, e a diferença entre atributo de instância e atributo de classe. Ordem sugerida de estudo:

| # | Arquivo | Tópico |
|---|---------|--------|
| 01 | `01_s4_ex1.py` | `__init__(titulo, artista)` — objeto nasce completo em 1 linha |
| 02 | `02_s4_ex2.py` | `__init__(nome, preco)` + `exibir()` + `aplicar_desconto(pct)` |
| 03 | `03_s4_ex3.py` | `__init__(nome, nota)` + lista de objetos criados em 1 linha cada |
| 04 | `04_s4_mini_desafio1_typeerror.py` | mini-desafio aula 1: provoca e registra o `TypeError` de argumento faltando |
| 05 | `05_s4_ex4.py` | `Personagem` 2.0: `__init__(nome, ataque=15)`, vida fixa 100, batalha da semana 3 refeita |
| 06 | `06_s4_ex5.py` | `Perfil` 2.0: `__init__(usuario)` com `seguidores = 0` fixo |
| 07 | `07_s4_ex7.py` | mini-desafio aula 2: `Aluno(nome, pontos=0)` + `ganhar_pontos()` + `situacao()` |
| 08 | `08_s4_ex6.py` | atributo de classe `total_criados` (exercício obrigatório da aula 3) |
| 09 | `09_s4_desafio_desconto_padrao.py` | mini-desafio aula 3 (extra 1): `Produto.desconto_padrao` como atributo de classe |
| 10 | `10_s4_desafio_matriculas.py` | mini-desafio aula 3 (extra 2): matrícula automática a partir do contador de classe |
| 11 | `11_playlist3.py` | Playlist 3.0: criação da `Musica` em 1 linha dentro do menu |
